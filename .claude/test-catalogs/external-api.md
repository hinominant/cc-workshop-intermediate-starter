# テストカタログ: 外部API連携系 (external-api)

## 適用条件
Specに以下のキーワードが含まれる場合に適用:
外部API, external, 連携, integration, サードパーティ, third-party, Stripe, SendGrid, Slack, Telegram, LINE, OpenAI, Claude, Anthropic, Google, AWS, webhook, SDK, クライアント, client

## 必須テスト項目

- EXT-001: 正常レスポンスの処理（期待するデータ形式の確認）
- EXT-002: APIタイムアウト時のリトライ or グレースフルフォールバック
- EXT-003: HTTP 4xx エラー時の適切なエラーハンドリング（ユーザー向けメッセージ変換）
- EXT-004: HTTP 5xx エラー時のリトライ（指数バックオフ、最大リトライ回数）
- EXT-005: レート制限（429 Too Many Requests）時のバックオフ戦略
- EXT-006: 不正なレスポンスボディ（JSON破損、予期しないフィールド）でクラッシュしないこと
- EXT-007: APIキー/トークンがログ・エラーメッセージに露出しないこと
- EXT-008: ネットワーク完全断絶時の挙動（DNS解決失敗、コネクション拒否）
- EXT-009: レスポンス形式の後方互換性（APIバージョンアップで新フィールド追加時にクラッシュしない）
- EXT-010: Webhook/コールバックの署名検証（不正なリクエストの拒否）

## オプショナルテスト項目

- EXT-OPT-001: サーキットブレーカーパターン（連続失敗時に一定期間リクエストを止める）
- EXT-OPT-002: フォールバック先への自動切り替え
- EXT-OPT-003: レスポンスキャッシュの有効期限管理
- EXT-OPT-004: 外部APIのモック/スタブを使ったテスト分離
- EXT-OPT-005: APIクレデンシャルのローテーション対応
