# テストカタログ: UIフロー系 (ui-flow)

## 適用条件
Specに以下のキーワードが含まれる場合に適用:
UI, 画面, ページ, フォーム, form, ボタン, button, モーダル, modal, ダイアログ, dialog, ナビゲーション, navigation, 遷移, フロント, frontend, コンポーネント, component, レンダリング

## 必須テスト項目

- UI-001: 正常フロー（入力→送信→結果表示）の全ステップ成功
- UI-002: 必須フィールド未入力での送信ブロック + バリデーションメッセージ表示
- UI-003: ブラウザ戻るボタンでの適切な挙動（フォーム再送信防止 or 状態復元）
- UI-004: ページリロードでの状態保持/喪失が仕様通りか
- UI-005: 同じ操作の連続実行（ダブルクリック、二重送信）での冪等性
- UI-006: 入力フィールドの最大長制限（maxlength超過時の挙動）
- UI-007: 特殊文字入力（<, >, &, ", ', スクリプトタグ）のXSS防止
- UI-008: エラー発生時のユーザー向けメッセージ（技術的エラーではなく人間が読めるメッセージ）
- UI-009: ローディング状態の表示（非同期処理中の適切なフィードバック）
- UI-010: 空状態（データ0件）の表示（空リスト、"データがありません"等）
- UI-011: レスポンシブ表示（モバイル幅320px〜デスクトップ1920px）
- UI-012: キーボード操作（Tab遷移、Enter送信、Escape閉じる）

## オプショナルテスト項目

- UI-OPT-001: ダークモード表示
- UI-OPT-002: オフライン時の挙動
- UI-OPT-003: クリップボードペースト時の入力処理
- UI-OPT-004: ドラッグ&ドロップの挙動
- UI-OPT-005: アクセシビリティ（WCAG 2.1 AA基準: スクリーンリーダー対応、色コントラスト比4.5:1以上）
- UI-OPT-006: 国際化（日本語/英語切替での表示崩れ確認）
