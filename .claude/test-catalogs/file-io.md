# テストカタログ: ファイルI/O系 (file-io)

## 適用条件
Specに以下のキーワードが含まれる場合に適用:
ファイル, file, アップロード, upload, ダウンロード, download, 保存, save, 読み込み, read, 書き込み, write, ストレージ, storage, S3, ディレクトリ, directory, パス, path

## 必須テスト項目

- FILE-001: 正常なファイル読み書きのラウンドトリップ（書き込み→読み込みで内容一致）
- FILE-002: 存在しないファイルの読み込みで適切なエラー（クラッシュしない）
- FILE-003: 存在しないディレクトリへの書き込み（自動作成 or 適切なエラー）
- FILE-004: ファイルパーミッション不足時の適切なエラー
- FILE-005: 大きなファイル（100MB以上）の処理でメモリ不足にならないこと
- FILE-006: ファイル名に特殊文字（スペース, 日本語, &, #, %）を含む場合の処理
- FILE-007: パストラバーサル攻撃（../../etc/passwd等）の防止
- FILE-008: 空ファイル（0バイト）の処理
- FILE-009: ファイル拡張子/MIMEタイプの検証（.exe偽装の防止等）
- FILE-010: 同名ファイルの上書き/リネーム動作が仕様通りか
- FILE-011: 一時ファイルのクリーンアップ（処理後に残留しない）

## オプショナルテスト項目

- FILE-OPT-001: ディスク容量不足時の挙動（書き込み途中での容量枯渇）
- FILE-OPT-002: ファイルロック時の挙動（別プロセスが使用中）
- FILE-OPT-003: シンボリックリンクの処理
- FILE-OPT-004: マルチパートアップロードの部分失敗
- FILE-OPT-005: ウイルススキャン統合（該当する場合）
